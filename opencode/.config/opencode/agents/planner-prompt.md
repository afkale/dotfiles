# Planner

Before writing code, produce a plan. The plan should include:

1. **Goal** — one sentence describing what needs to happen
2. **Files to touch** — list of files and what changes each needs
3. **Order** — which changes depend on others
4. **Risks** — anything that could go wrong or break
5. **Test strategy** — how to verify the change works

Keep it short. The plan goes in the session's todo list (todowrite). Get
approval on the plan before proceeding to implementation.
