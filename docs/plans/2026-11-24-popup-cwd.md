## Goal

Implement issue #9. Each `M-1` open starts a new shell in the directory of the pane it was
opened from. Today the popup session is created once, so later opens keep a stale directory.

Decision from the issue (user-confirmed): **start fresh**. The popup session is destroyed when
the popup closes, so each open is a new shell. Shell history and running processes do not
survive between opens.

## Change

1. **Popup script** (`tmux/.config/tmux/scripts/popup.sh`): on the popup's own server, turn on
   `destroy-unattached` for the popup session, so it is removed when the last client detaches.
   The existing guard that creates the session only when missing stays, so every open after a
   close creates a fresh session with `-c "$PWD"`.
2. **Keep isolation as is**: own socket, `status off`, `unbind -a` for root and prefix tables,
   only `M-1` bound to detach, copy-mode keys and clipboard command unchanged.
3. **Keep the test seam**: `TMUX_POPUP_SOCKET` and `TMUX_POPUP_SESSION` keep working.
4. **Tests**: add `tmux/.config/tmux/scripts/popup_test.sh`, a POSIX-ish bash script with no new
   dependencies. It starts a throwaway server on a unique socket, runs the popup script in
   detached mode from two directories (one with a space in the name), and asserts on
   `#{pane_current_path}` after each open. It always kills its server on exit (`trap`).
   Follows the disposable-socket pattern in `scripts/doctor.sh`.

## Non-goals

- No change to `M-1` binding in `tmux.conf` (size, position, arguments).
- No change to the pane picker (`M-d`), tool popups, or agent-manager sessions.

## Risks

- `popup.sh` is run with `exec tmux attach`, which needs a TTY. The test must not depend on
  attach. It should exercise the create-and-detach path, not the interactive attach.
- `destroy-unattached` also applies if the popup is attached from another terminal and then
  detached. That is the intended behaviour here.

## Verification

- `bash -n` and `shellcheck -x` on the changed scripts.
- `bash tmux/.config/tmux/scripts/popup_test.sh` passes; it fails on the current code.
- `make doctor` passes.
- Manual check in the real tmux: `M-1` from project A, `cd` nowhere, then `M-1` from project B
  lands in B.
